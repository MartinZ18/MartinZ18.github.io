# martinz18.github.io

Portafolio personal. HTML y CSS a mano, sin framework ni build step.

**En vivo:** https://martinz18.github.io

## Estructura

Un solo archivo, `index.html`, con el CSS embebido. Tipografías desde Google Fonts.

- Soporta tema claro y oscuro según la preferencia del sistema.
- Responsive desde 360px.
- Sin JavaScript.

## Publicar cambios

Editar `index.html` y hacer push a `main`. GitHub Pages republica solo.
